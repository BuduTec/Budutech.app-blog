# BuduTech Knowledge Hub

Main site: https://budutech.app
Blog subdomain: https://blog.budutech.app

## Phases included
- Phase 1: foundation, homepage, article pages, categories, legal pages
- Phase 2: search, category pages, related content, table of contents
- Phase 3: tools, quizzes and calculators

## Run locally
npm install
npm run dev

## Deploy
Push to GitHub and connect the repo to Vercel.
